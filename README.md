Kyron Coach is a digital coaching and athlete-management platform designed to help combat sports coaches organise their athletes, structure training programmes, manage competitions, and oversee athlete development from a single workspace.

Built as part of the **Areté** ecosystem, Kyron Coach serves as the coach-facing application, providing the tools needed to manage the complete coaching workflow — from onboarding athletes and planning training sessions to organising camps and preparing athletes for competition.

The goal is simple: give coaches a structured digital environment to develop better athletes, make informed decisions, and manage their teams more effectively.

---

## 1. The Idea Behind Kyron

Combat sports training involves much more than showing up at a gym and completing workouts.

A coach must manage multiple athletes, understand their individual strengths and weaknesses, plan training sessions, monitor progress, organise camps, prepare athletes for competitions, and maintain a consistent training structure.

Much of this process is traditionally handled through notebooks, spreadsheets, messaging applications, and disconnected tools.

**Kyron aims to bring these workflows together.**

Instead of treating training as an isolated activity, Kyron approaches coaching as a continuous athlete-development process.

It provides coaches with a centralised platform to:

- Maintain organised athlete profiles.
- Plan and schedule individual and group training sessions.
- Track workout structures, sets, repetitions, rounds, and duration.
- Maintain an exercise library for structured training.
- Organise training camps.
- Manage competitions and preparation.
- Monitor scheduled activities and athlete development.
- Keep coaching operations organised through a unified dashboard.

Kyron is designed around the idea that every athlete has a journey, every training session has a purpose, and every competition is part of a larger development process.

## 3. Application Modules

Kyron Coach is organised into specialised modules, each addressing a different aspect of coaching and athlete management.

### 3.1 Dashboard — Pantheon

The Dashboard acts as the central command centre of the application.

It provides coaches with an overview of their operations and helps them understand what requires attention.

**Purpose:**
- Provide a central overview of coaching activities.
- Make important information accessible without navigating through multiple sections.
- Give coaches a starting point for managing their daily workflow.

The Pantheon identity represents the central place from which the coach oversees the entire system.

### 3.2 Athlete Management — Spartan Helmet

The Athletes module provides a structured way to manage the people a coach trains.

Each athlete can have an individual profile, allowing the coach to maintain athlete-specific information and associate training activities with the correct person.

**Core functionality:**
- Create and manage athlete profiles.
- Maintain athlete information.
- Access individual athlete records.
- Associate athletes with training sessions.
- Organise athletes within the coaching workflow.
- Support athlete-specific development and tracking.

The objective is to move away from scattered athlete records and towards a structured athlete-management system.

### 3.3 Training Management — The Sword

Training is one of the core modules of Kyron Coach.

It allows coaches to create and schedule structured workouts for one or multiple athletes.

**Core functionality:**
- Assign workouts to selected athletes.
- Select exercises from the exercise library.
- Categorise training sessions.
- Associate workouts with training camps.
- Schedule sessions by date and time.
- Add optional training notes.
- Choose between different workout tracking methods.

**Supported tracking methods:**

| Tracking method | Information recorded |
|---|---|
| Sets & Reps | Number of sets and repetitions per set |
| Time | Workout duration and rounds |
| Both | Combined time-based and sets-and-reps tracking |

Training sessions can be scheduled first and subsequently marked as completed. Completed sessions can then contribute to the athlete's training history.

The Training module is intended to make workout planning structured, repeatable, and easier to manage.

### 3.4 Exercise Library

The Exercise Library provides a collection of exercises that coaches can use while creating training sessions.

Rather than manually entering every workout from scratch, coaches can select exercises from an organised list.

Exercises can be associated with training categories, helping maintain consistency when planning different types of sessions.

The library supports the wider objective of building structured training programmes rather than relying on informal workout descriptions.

### 3.5 Schedule Management — The Calendar

The Schedule module provides a calendar-oriented view of planned coaching activities.

It helps coaches keep track of upcoming sessions and organise their training commitments.

**Purpose:**
- View scheduled training activities.
- Keep track of workout dates and timings.
- Organise upcoming sessions.
- Maintain visibility over the coaching calendar.

The Schedule module complements Training by providing a broader view of planned activities rather than focusing only on the creation of an individual workout.

### 3.6 Training Camps

Training camps allow coaches to organise athletes and training activities around a dedicated camp.

A camp can be associated with participating athletes and used when scheduling workouts.

**Core functionality:**
- Create and manage training camps.
- Associate athletes with camps.
- Link scheduled workouts to a camp.
- Maintain a connection between camp participation and training activities.

This makes it easier to organise focused training periods, group preparation, and structured athlete development.

### 3.7 Competitions — Crossed Spears

The Competitions module represents the competitive side of athlete development.

Competition management is an important part of combat sports coaching because training programmes are often structured around upcoming events.

Kyron includes a dedicated area for managing competition-related information and keeping competitive activities within the coach's workflow.

The module is designed to complement training and camp management, helping coaches approach competition preparation as part of a larger athlete-development process.

### 3.8 Forms and Supporting Workflows

The application also includes forms and supporting interfaces used throughout its management modules.

These provide structured ways to enter and manage information rather than relying on unstructured manual records.

Together, the modules create a connected workflow for managing athletes, training activities, camps, competitions, and schedules.

## 4. The Kyron Workflow

Kyron is designed around a connected coaching workflow.

A typical coaching process can be represented as:

1. **Manage Athletes** — Create and maintain athlete profiles.
2. **Organise Training** — Select exercises and structure workouts.
3. **Schedule Sessions** — Assign athletes and set dates and timings.
4. **Manage Camps** — Group athletes into dedicated training camps.
5. **Prepare for Competition** — Manage competition-related activities.
6. **Track Development** — Maintain training records and completed-session history.

The different modules are intended to work together rather than function as isolated tools.

## 5. Design Philosophy and Visual Identity

Kyron's visual identity draws inspiration from classical Greek architecture, mythology, and the ideals associated with discipline, excellence, and athletic development.

The interface follows a refined dark aesthetic with a restrained metallic-gold accent system.

### Colour Palette

| Colour | Purpose |
|---|---|
| Black | Primary interface and backgrounds |
| Gold | Accents, highlights, and emphasis |
| Ivory | Readable text and softer contrast |

The combination is intended to create a premium, disciplined, and recognisable visual identity.

### Typography

The design incorporates **Cormorant Unicase**, a typeface chosen to reinforce the application's classical Greek-inspired character.

### Iconography

The navigation system uses symbolic references to Greek and Spartan imagery.

| Module | Visual Symbol | Meaning |
|---|---|---|
| Dashboard | Pantheon | Central command and oversight |
| Competitions | Crossed Spears | Competition and combat |
| Schedule | Calendar | Planning and organisation |
| Training | Sword | Discipline and preparation |
| Athletes | Spartan Helmet | Strength, identity, and athletic development |

The visual language is intentionally softer and more refined than an aggressive combat-sports aesthetic.

The objective is to combine the seriousness of athletic performance with the elegance of classical design.

## 6. Technology Stack

Kyron Coach uses a modern web-development stack.

### Frontend

- **React** — Component-based user interface.
- **TypeScript** — Type safety and maintainable application logic.

This separation makes it easier to maintain individual modules and extend the application without unnecessarily affecting unrelated functionality.

## 7. Running the Project Locally

### Prerequisites

Make sure the following are installed:

- Node.js
- npm
- Git

### Installation

Clone the repository:

```bash
git clone <YOUR_REPOSITORY_URL>
```

Navigate into the project directory:

```bash
cd <PROJECT_DIRECTORY>
```

Navigate into the frontend directory if the repository contains separate frontend and backend folders:

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Vite will provide a local development URL in the terminal, usually:

```text
http://localhost:5173
```

### Production Build

To generate a production build:

```bash
npm run build
```

To run the production preview:

```bash
npm run preview
```
